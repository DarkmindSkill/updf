JPG to PDF maker (Node.js 18+)

OPTION 1: single file, nothing to install
  node app.js
  Open http://localhost:3000
  (PDF and crop libraries load from the CDN. For offline use run:
   npm install pdf-lib cropperjs)

OPTION 2: Express version (server.js + public/index.html)
  npm install
  npm start
  Open http://localhost:3000

Phone: open the "Phone:" link printed in the terminal, on the same Wi-Fi.
Different port: PORT=3001 node app.js
Do not edit the comment block at the bottom of app.js.
